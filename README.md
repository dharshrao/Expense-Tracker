# Expense Tracker

A simple Python console application to track daily expenses.

## Features
- Add Expense
- View Expenses
- Calculate Total Spending
- Delete Expense
- Save and Load Data from File

## Technologies Used
- Python
- Dictionaries
- File Handling
- Loops and Conditions

## How to Run

1. Install Python
2. Download the files
3. Run the program:

python expense_tracker.py
